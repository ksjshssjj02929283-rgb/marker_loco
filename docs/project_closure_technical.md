# Marker 6DoF 系统交付说明

## 交付结果

已交付从相机输入到位姿输出、轨迹展示和离线评估的一套工具链，适用于安装在同一刚体上的多面 ArUco Marker。

| 能力 | 交付内容 |
| --- | --- |
| 位姿跟踪 | 多面刚体标定、单面 IPPE 候选、多面联合 PnP、重投影与时间连续性门控、失锁分段 |
| 设备与数据 | Intel RealSense D455 RGB/RGB-D、T265 双鱼眼采集；实时跟踪、录制和离线回放 |
| 坐标与呈现 | 相机系相对 XYZ 与四元数、网页 3D 轨迹、CSV 与逐帧诊断；支持经实测外参换算 TCP |
| 评估与复现 | 合成闭环、标定/rig/TCP 工具、静态与动态评估、报告生成和自动化测试 |

## 处理流程

```text
相机帧与标定
  -> Marker 检测与角点提取
  -> 多面刚体位姿联合求解
  -> 重投影、连续性与跟踪状态检查
  -> 可选 RGB-D 局部精修及 RGB 回退
  -> 相对位姿、轨迹与逐帧诊断
  -> 实时展示、录制文件或离线报告
```

## 运行与使用边界

- 相对轨迹以首个接受测量的位姿为参考；输出不是全局坐标真值。
- TCP 结果取决于正确且经过复核的 `T_reference_TCP` 外参。示例值不能作为实测外参。
- T265 VIO 输出是单次会话局部坐标；缺失或无效数据会造成轨迹断段。
- RGB-D 只对已有 RGB 位姿做局部精修；深度几何不可靠或时间不同步时回退到 RGB。
- 相机内参、Marker 实测尺寸和刚体 rig 配置必须与实际设备和安装相符。

## 代码入口

- `src/marker6dof/tracking.py`：多面跟踪、质量门控与相对轨迹。
- `src/marker6dof/rgbd.py`、`realsense_depth.py`：深度优化和坐标适配。
- `src/marker6dof/d455.py`、`t265.py`：设备采集适配。
- `src/marker6dof/commands/`：实时、标定、回放、评估与报告命令。
- `configs/`、`tests/`：配置示例和自动化验证。

运行、录制与配置入口见 [项目 README](../README.md)、[配置说明](../configs/README.md)、[录制指南](recording_guide.md) 和 [TCP 外参说明](tcp_calibration.md)。

## 交付范围结论

交付范围是相机系相对位姿跟踪与配套工程工具。跨设备绝对精度、TCP 精度、跨会话世界定位和 RGB-D 硬件精度收益，仍需独立真值和受控实验验收。
