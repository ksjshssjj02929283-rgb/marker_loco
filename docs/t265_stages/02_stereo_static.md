# T265 双鱼眼联合定位的双夹爪 Marker 中心轨迹

## 实验设置

本阶段使用 T265 同步的左右鱼眼，在已知双目外参下将两个眼的夹爪位姿统一到左鱼眼坐标系。双眼都有有效估计且彼此一致时联合定位；仅一眼有效时保留单眼结果。相机仍按静止处理。

左夹爪使用 5×5 ArUco、边长 54.6 mm；右夹爪使用 6×6 ArUco、边长 56 mm。两侧均使用 ID 2–5 的多面标定几何，结果是各自 Marker 立方体中心。所有任务按共同双目帧处理。

## 与单目静止阶段对比

相同录制、相同任务帧范围内，双夹爪同帧有效数分别从 **697 → 714**、**673 → 690**、**734 → 806**，增加 17、17、72 帧。整理桌面的增益最明显，说明第二只眼在部分遮挡和视角变化时提供了额外可用观测。这些数字说明有效帧覆盖率变化，不代表绝对位姿精度提升；精度仍需外部真值验证。

## 结果解释与边界

两个鱼眼的原始画面均为灰度，彩色部分为检测与轨迹叠加。位姿是 Marker 立方体中心，**不是夹爪 TCP**。轨迹位于假定静止的左相机坐标系；如果相机移动，曲线中会混入相机自身运动。结果适合检查联合定位、可见性与轨迹连续性，训练使用前需确认坐标参考点和相机运动处理方式。

## 复现

逐帧结果来自仓库的 `scripts/replay_dual_t265.py`，使用相应任务录制和 `configs/local/t265_left_5x5_54p6_rig.json`、`configs/local/t265_right_6x6_56_rig.json`。视频合成命令：

```bash
.venv-t265/bin/python scripts/export_t265_task_videos.py \
  --result-root outputs/t265_stages/02_stereo_static
```
