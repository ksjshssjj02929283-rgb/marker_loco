# D455 相机内参：不同标定方式的结果

实物已确认：6×6 AprilGrid，黑框边长 0.10 m，白色间隙 0.03 m，`tagSpacing=0.3`。仅比较 RGB 单目内参，分辨率均为 1280×720。

目前已得到 **OpenCV 和原生 Kalibr 两种算法**的实际结果。出厂参数作为基准。OpenCV 导出的 Kalibr 兼容 YAML 与原生 Kalibr 运行结果分别列出。

数据：前两包为 `d455_1019_1`、`d455_1019_2`；第三包为 `d455_aprilgrid_1020_retry2`。本机录制在 `captures/calibration/d455/`，Kalibr 转换 bag 在 `captures/calibration/kalibr_d455/`；它们不随 Git 分发。联合数据共有 5,776 张原始图像；OpenCV 每 5 帧抽样，检测到 888 个可用视角，均匀选取 600 个，其中 480 个训练、120 个留出。训练剔除 1 个异常视角，最终拟合 RMS 为 **0.160514 px**。

Kalibr 的结果文件明确记录 Size=0.1 m、Spacing=0.03 m，使用 `pinhole-radtan`；其报告中的 X/Y 重投影标准差为 **0.271907 / 0.265346 px**。两种算法的训练角点、帧筛选和畸变阶数不同，训练误差不能直接用于排名。

## 相同独立数据验证

为避免把参与训练的第三包当独立验证，另外用前两包训练 OpenCV，得到 `K=[645.265162, 645.070936, 642.309773, 353.921511]`。这一组和 Kalibr 前两包结果均未使用第三包训练。

统一使用第三包每 60 帧抽样得到的 **30 个相同视角、相同角点**，逐视角只重新估计板位姿，不改内参，不删验证视角。指标为各视角二维重投影 RMS 的分位数。

| 参数来源 | p50 / px | p95 / px | 最大值 / px | p95 相对出厂 |
| --- | --- | --- | --- | --- |
| 出厂 | 0.1582 | 0.2235 | 0.6351 | 基准 |
| OpenCV：前两包 | 0.1358 | 0.1864 | 0.5978 | 降低 16.6% |
| Kalibr：前两包 | 0.1594 | 0.2918 | 0.6369 | 增加 30.5% |

此表使用修正后的 OpenCV 角点，是固定观测条件下的结果；它同时受模型阶数、训练视角选择及检测器差异影响，不能直接解释为 Kalibr 算法更差。OpenCV 另有 250 个跨包验证视角，p95 从出厂 0.2240 降至 0.1867 px，趋势一致。

## 重复标定与当前判断

OpenCV 前两包标定与第三包独立标定的 `fx/fy` 分别为 `645.265162/645.070936`、`645.275810/645.063704`，相差约 **0.0017% / 0.0011%**；主点最大差异约 **2.22 px**。这说明焦距重复性较好，主点仍有一定采集相关变化。

原生 Kalibr 在第三包上的独立标定也已完成：`K=[643.150241, 642.976974, 640.280919, 351.651593]`，`D=[-0.041770661, 0.029498609, -0.000384946, 0.000119707]`，X/Y 重投影标准差为 `0.249576 / 0.253223 px`。相对前两包，fx/fy 变化约 **0.425% / 0.433%**。其训练残差更小，并不能证明这组参数对定位更好；本轮统一独立验证和历史回放使用的是 Kalibr 前两包参数。

**实测板配置已能正常标定；OpenCV 获得了低重投影误差和跨包改善。Kalibr 也得到接近的焦距，但目前这组参数在统一验证中未优于出厂。最终是否切换，应以历史 Marker 与激光真值评估为准。**

之前的图像尺寸判断受角点偏向黑框内部影响；已修正标定检测器的黑边配置和亚像素搜索窗口。合成黑框边缘回归与相机模型相关检查共 12 项通过，图像几何复核得到三包间隙比中位数约 0.30025，与实测一致。
