# Marker 6DoF 项目自研说明与效果评估

核查日期：2026-10-22。本文根据当前源码、实验说明和本地可复核结果整理，面向技术汇报。这里的“自研”指项目团队围绕特定多面 Marker、相机和实时使用条件完成系统设计、实现、标定、门控、集成与验证；底层使用 OpenCV、RealSense SDK、Kalibr 等公开工具和算法，不表示所有数学方法或检测器均为原创。

## 1. 项目解决什么问题

项目输入是 D455 RGB/RGB-D 或 T265 同步双鱼眼图像，以及安装在同一刚性物体上的多个平面 ArUco Marker。输出是该物体相对相机的 6DoF 位姿和相对运动轨迹，并可按实测刚体到 TCP 外参换算夹爪 TCP 位姿。项目需要解决的不只是“检测到一个方块”，而是在单面观测退化、多个面间歇可见、深度数据不稳定、相机时间戳和实时显示等条件下，持续给出有质量状态、可诊断、可离线复验的结果。

```text
相机图像 / 设备时间戳 / 标定
  -> 亚像素 Marker 角点
  -> 单面 IPPE 候选与多面刚体几何
  -> 同一刚体坐标系下联合角点 PnP
  -> 按面重投影检查、候选连续性和时序门控
  -> 可选 RGB-D 面内平面精修
  -> MEASURED / WARN / LOST 状态及轨迹分段
  -> 相对 XYZ + 四元数 / 实时工作台 / 离线评估
```

## 2. 自研工作如何落到代码

### 多面刚体定位

团队实现了多面 Marker 标定与在线跟踪链路：由重叠观测估计 Marker 间固定变换，按参考面组织刚体几何；在线阶段将可见面的角点映射到共同刚体坐标系，对单面 IPPE 的双候选进行多面几何评分，并用同一刚体的角点联合求解位姿。重投影质量按面核验，坏面可被剔除后重新求解；时序连续性只用于相似候选的消歧，异常观测会被拒绝，而不是用平滑掩盖定位错误。实现位于 [tracking.py](../src/marker6dof/tracking.py) 与 [localization.py](../src/marker6dof/localization.py)。

### 设备适配与 RGB-D 精修

RGB-D 不是简单地取角点附近深度再插值。项目用 RealSense SDK 从原始深度帧生成点云，应用深度到彩色相机的真实外参并检查彩色/深度时间差；在 Marker 面内部区域筛选点，对每面做鲁棒平面拟合，再以 RGB 角点重投影残差和深度点到平面残差联合优化位姿。几何支持不足、深度与 RGB 不一致、最终重投影恶化或时序异常时，系统保留 RGB 结果并记录回退原因。SDK 适配与优化分别位于 [realsense_depth.py](../src/marker6dof/realsense_depth.py) 和 [rgbd.py](../src/marker6dof/rgbd.py)。

### 从算法到可复现工具

自研范围还包括 D455/T265 采集和实时接入、原始数据录制、离线 RGB/RGB-D 回放、标定配置、TCP 外参、轨迹和质量可视化，以及合成真值、激光静态点、已知位移、静态噪声等评估命令。保留输入帧、设备时间戳、角点、逐帧结果和拒绝原因，使算法变化可以在同一数据上对照；测试覆盖几何、坐标变换、跟踪门控、回退与命令入口。此系统工程能力使结果可以复现并定位问题，但本身不等价于精度领先。

## 3. 与基线比较：目前证据支持哪些优势

需要区分三种比较对象：开源库提供的检测器/PnP/相机 SDK；设备出厂内参；以及本项目自己的算法变体。以下结果直接来自项目报告，基线、指标和适用范围各不相同，不能合并成一个“全面优于开源”的结论。

| 证据 | 对照与方法 | 结果 | 可以支持的结论 |
| --- | --- | --- | --- |
| 独立图像角点重投影 | 同一组未参与标定的 30 个视角；OpenCV 前两包模型对比出厂相机模型 | p95 从 0.2235 px 降至 0.1864 px，降低 16.6%；本项目 Kalibr 前两包模型在同组数据升至 0.2918 px | 针对该相机和这组独立图像，OpenCV 重标定改善了重投影尾部误差；不同标定方法并非都改善 |
| 20–150 cm 激光静态相对位移 | 36 个静态点、4 种尺寸/单面或双面采集；出厂内参对比 Kalibr 第三包 B | 四组累计点间 RMSE 均下降：19.57→17.42、36.37→33.32、44.59→41.76、57.22→54.91 mm，约改善 4%–11%；逐点位姿输出率相同 | B 在本批完整距离范围内相对出厂有一致改善，且没有靠降低输出率换取误差；远距离误差仍大 |
| 20–80 cm 激光静态相对位移 | 同一实验中的 Kalibr 前两包 A | 截至 80 cm，四种采集的累计 RMSE 均较出厂降低约 5%–13%；截至 60 cm，三套标定在四种采集下都低于 5 mm | 标定参数与采集配置会影响特定工作距离的相对位移质量；不能外推到未测距离 |
| 检测覆盖 | D455 47.5 mm 单面录制，2,474 帧 | 覆盖率 92.9%；最远一次检测约 1.53 m，重投影误差 0.35 px | 证明目标录制工况下远距离仍可观测，不等于 1.53 m 精度保证 |
| 合成真值闭环 | 60 帧合成数据，全链路输出与生成真值比较 | 100% 帧得到 MEASURED；位置误差 p50 2.2 mm、p95 7.0 mm，姿态误差 p50 1.3°、p95 3.2° | 证明配置、定位、跟踪、输出和评估链条可工作；不是实机精度指标 |

激光表中的“RMSE”是截至对应距离、多个静态测点之间的**点间距离误差**，不是相机坐标下绝对 XYZ 误差，也不是每帧抖动。详细距离分布、输出率、模型和评估口径见 [2026-10-20 内参对比报告](marker_intrinsics_comparison_20261020.md)。该实验每个位置只有一次录制；其“激光真值”对照用于本批相对位移评估，不能据此声称对所有相机、Marker、姿态和动态速度普遍领先。

## 4. 关键结果及其边界

- 多面刚体联合 PnP 与时序门控形成了可运行的相对 6DoF 系统；静止硬件测试在约 0.3 m 的条件下观察到最佳约 0.06–0.26 mm 的单轴标准差，轻微手持扰动时约 1–2 mm。静态重复性是噪声，不代表绝对准度。
- 早期 200 mm 手动 Z 向位移估计误差约 4.9 mm（2.4%），但测试存在明显侧向和高度移动，不能作为受控单轴精度验收。
- 重标定效果因数据而异。B 组在本批 150 cm 累计结果上改善；A 组在 80 cm 改善但并非所有距离和组合都更优。150 cm 的累计误差仍约 17–58 mm，37.5 mm 双面数据在 120 cm 的输出率仅约 30%。当前证据不支持“远距离精度已达毫米级”或“检测范围扩大”。
- RGB-D 优化具备真实设备坐标转换、时间同步检查、鲁棒平面、联合目标函数和失败回退，但现有黑色 Marker 的一次完整 D455 回放中，877 帧有 0 帧真正接受深度精修。因此，这条自研链路已验证集成和保守回退，**尚未证明实机精度优于 RGB-only 或开源实现**。参考 [RGB-D 效果说明](depth_camera_effect.md) 与 [RGB-D 项目梳理](project_review_rgbd.md)。
- 新的权重、静态联合姿态等变体已有激光数据对照，但结果并不总是优于统一基线；例如静态多帧联合拟合在 150 cm 累计误差约 40 mm，与逐帧均值约 40 mm 接近。自研优化必须逐项经过实测筛选，不能凭算法复杂度推定更好。

## 5. 汇报时可以使用的结论

> 本项目围绕多面 ArUco 刚体 6DoF 跟踪，自研了从多面几何标定、联合角点定位、时序质量门控到 RGB-D 局部精修和实时/离线评估的完整工程链路。在 D455 指定数据集上，Kalibr 第三包内参相对设备出厂基线使四种采集配置的 20–150 cm 累计静态相对位移 RMSE 一致下降约 4%–11%，位姿输出率保持不变；另有独立图像重投影 p95 下降 16.6% 的 OpenCV 标定结果。改进目前是对特定设备、数据和距离范围成立的实测结果。项目也已明确识别深度融合尚无实机精度收益、远距离误差和部分配置低覆盖等限制，后续需通过受控位移平台、重复采集和独立动态真值完善验收。

简短表述：**自研形成完整、可复现、可诊断的多面 6DoF 工程系统；在当前 D455 基准实验中，部分标定方案相对出厂基线取得约 4%–11% 的全范围相对位移误差改善，输出率不降。现有证据支持“特定工况下有实测改进”，尚不支持“全面优于开源方案”。**

## 6. 后续对比验收建议

1. 固定相机、Marker 尺寸、刚体/TCP 几何、数据帧和时间戳，逐项对比项目版本、OpenCV/开源参考实现、相机出厂内参；先明确比较的是检测、定位、跟踪还是整个系统。
2. 使用机械导轨或机器人给出已知 3D 位移与姿态真值，每个距离和姿态重复录制；同时报告 XYZ/角度误差、静止重复性、输出率、失锁/误锁率和延迟。
3. 分距离与单面/多面报告，不只提供累计统计；保留原始输入与逐帧结果，独立数据用于定参后验证。
4. RGB-D 先换用深度覆盖可靠的非黑、非镜面目标，确认实际融合帧比例，再与同帧 RGB-only 结果对照独立真值和处理耗时。
5. 变更标定、权重或门限后复用同一数据回放，并以新录制和独立真值复核，防止用同一数据调参后报告为泛化提升。
