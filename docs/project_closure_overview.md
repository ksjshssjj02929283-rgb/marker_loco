# Marker 6DoF 项目结项摘要

## 结项结论

**系统已形成可运行、可回放、可评估的多面 Marker 6DoF 跟踪链路。**合成闭环通过；指定 D455 静态实验中，Kalibr 第三包内参使四种配置的全范围相对位移 RMSE 改善约 4%–11%，输出率不变。现有数据尚不能支持跨设备、跨工况的绝对精度承诺，也未证明 RGB-D 在真实设备上有稳定精度增益。

## 三项可汇报成果

| 成果 | 结果 | 结论 |
| --- | --- | --- |
| 跟踪系统与工具链交付 | 多面定位、D455/T265 采集、实时展示、离线回放、评估与报告链路已打通 | 可运行、可复现、可诊断 |
| 算法闭环验证 | 合成 60 帧全部通过；位置误差 p95 6.98 mm，姿态误差 p95 3.18° | 验证软件链路和算法闭环，不代表实机精度 |
| D455 标定对比 | 36 个静态点、4 种 Marker 配置；Kalibr 第三包全范围 RMSE 均改善约 4%–11%，输出率相同 | 在本批静态基准上有一致但有限的改善 |

## 关键边界

- **远距检测不等于远距精度：**一次手持录制覆盖率 92.9%，最远观测约 1.53 m。
- **动态结果不是绝对精度：**三段激光对照在事后时移和刚体对齐后，轨迹位置 RMSE 为 19.49–28.98 mm。
- **RGB-D 收益未建立：**早期 877 帧回放接受深度精修 0 帧；另一批静态数据中有 1,523/4,574 个有效帧融合，但未观察到全距离稳定改善。

## 结项判断

**工程交付完成，受控实机精度验收未完成。**当前成果足以支撑系统集成、复现实验和下一阶段验收；正式精度指标仍需独立位置/姿态真值、已验收外参及受控重复运动实验。

下一阶段优先补齐三项：机器人或导轨动态真值；相机、rig 与 TCP 外参复核；同步 RGB 与 RGB-D 在同一基准下的逐帧对照。
