# Marker 6DoF 验证结果

## 结论先行

1. **软件闭环已验证。**合成数据 60/60 帧通过。
2. **D455 标定改进有限但一致。**Kalibr 第三包在本批四种 Marker 配置的静态相对位移实验中均优于出厂参数约 4%–11%，逐点输出率相同。
3. **实机绝对精度和 RGB-D 精度收益尚未验收。**现有实验能说明观测能力、短期重复性和特定工况下的相对误差，不能替代受控真值。

## 核心结果

| 验证项 | 结果 | 可以得出的结论 |
| --- | --- | --- |
| 合成闭环 | 60 帧全部通过；位置误差 p95 6.98 mm，姿态误差 p95 3.18° | 算法和数据链路闭环有效；不代表实机误差 |
| 静态重复性 | D455 约 0.3 m，最佳单轴标准差 0.06–0.26 mm；轻微扰动约 1–2 mm | 该距离和录制条件下短期输出稳定；不是绝对准确度 |
| 远距检测 | 手持录制 2,474 帧，覆盖率 92.9%；最远观测约 1.53 m | 系统能在该距离观测到 Marker；未给出该距离精度保证 |
| 独立图像标定比较 | 30 个留出视角：OpenCV 前两包重投影 p95 0.1864 px，出厂 0.2235 px，下降 16.6%；Kalibr 前两包为 0.2918 px | 图像重投影指标因标定方案而异，不能简单认定所有标定结果都更好 |
| 静态激光相对位移 | 36 个点、4 种配置、20–150 cm；Kalibr 第三包 RMSE 改善约 4%–11%，输出率相同 | 指定数据集内有相对位移改善，但远距离误差仍明显 |
| 动态激光轨迹 | 3 段运动；对齐及估计时移后，轨迹位置 RMSE 19.49–28.98 mm；1 秒位移长度 RMSE 10.15–14.13 mm | 可作动态相对轨迹对照；不是绝对世界坐标精度 |
| RGB-D 真实评估 | 早期 877 帧接受融合 0 帧；另一静态数据集 4,574 个有效帧中 1,523 帧融合 | 能诊断失败并保守回退；尚未证明真实融合带来稳定精度收益 |

## 关键口径

- **静态相对位移：**按各激光距离点的成功帧位姿均值计算点间距离 RMSE，不做尺度或空间拟合；不是单帧 XYZ 或姿态误差。150 cm 累计 RMSE 为 17.42–54.91 mm，≤5 mm 连续通过端点仍在 60/80 cm。
- **动态轨迹：**轨迹位置比较进行了事后时移估计和刚体对齐，激光采样约 10 Hz；近直线运动对旋转约束弱，结果不能作为绝对坐标验收。
- **RGB-D：**两次评估使用不同录制和工况，不能将融合帧数合并为单一覆盖率或直接比较；离线收紧门限也未形成全距离一致改善。
- **早期手持位移：**200 mm 光轴移动估计为 195.1 mm，但伴随约 18 mm 横向和 71 mm 竖向移动，不属于受控单轴精度实验。

## 验收缺口

进入正式精度验收前，建议补齐机器人或导轨独立真值、已复核相机/rig/TCP 外参，以及多距离、多轴平移与旋转下的重复采集。RGB-D 需在同步原始数据和深度表现可靠的 Marker 表面上，与 RGB-only 逐帧对照。
