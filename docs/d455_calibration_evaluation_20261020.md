# D455 标定评估结论：OpenCV vs 原生 Kalibr vs 出厂

## 结论

实测板为 6×6、tag 黑框 10 cm、白色间隙 3 cm，所有本轮标定均采用 `tagSpacing=0.3`。已完成 OpenCV 与原生 Kalibr 标定，并以出厂参数为基准重跑 36 段激光静态数据和 11 段 Marker 视频。标定已跑通，但定位精度没有全面提升，不能据此声称精度范围扩大。

20～150 cm 累计 RMSE 相对出厂的改善率（正值改善、负值变差），按下表四组顺序：OpenCV 为 +0.7% / +0.7% / -1.1% / -1.1%；Kalibr 为 -0.8% / +0.0% / -1.2% / -1.2%。

## 评估口径与建议

激光评估沿用 2026-10-15 的 36 段原始 RGB-D 记录、历史 rig 与 Marker4 外法线 25.5 mm 测量点，深度权重 0.2、尺寸门限 1 px；每点使用全部成功帧求三维均值，再比较所有点对长度和原始激光 XYZ 真值，不做空间或尺度拟合。

出厂对照始终使用各段录制的原始参数；其焦距不一定等于上表标定 bag 的 CameraInfo。新模型同时用于 RGB 求解和深度投影，深度原生参数与外参保留。三组各 4,890 个输入彩色帧，36/36 段彩色与深度时间戳序列一致；旧表 36 格已独立复算一致。每位置只采集一次，结果不能推导绝对 XYZ、姿态或动态精度。

**当前建议：保留出厂参数作为默认，保存本轮两套标定供明确场景选用；暂不把重新标定视为解决中远距离误差的方法。** 板尺寸已实测，角点问题已修复，后续应重点排查远距离角点质量、rig/测量点几何与深度融合。
