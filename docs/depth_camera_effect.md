# Marker 6DoF 项目梳理与深度相机效果说明

> 文档状态：内部技术说明（草案）
> 发布主体：项目团队
> 读者：定位 / 深度融合相关开发者与项目负责人
> 数据来源：`docs/project_review_rgbd.md`、`docs/accuracy_preliminary.md` 与当前工作树源码，核查时点 2026-09 至 2026-10

## 一、摘要

项目估计 47.5 mm 多面 ArUco 刚体在相机光学坐标系中的相对 6DoF 位姿，D455（RGB-D）与 T265（双鱼眼 stereo）为两条独立后端。

深度相机的价值在于补足 RGB PnP 在景深（Z）方向的弱点：深度面提供"法向 + 沿法向位置"约束，与 RGB 角点联合优化。**但当前真实数据下深度融合的实际接受率为 0**——黑色 Marker 的深度通道不可用（系统性偏差 +0.33~+0.41 m），877 帧完整回放中没有任何一帧通过融合门控，因此 `--use-depth` 的实际效果等于 RGB-only。合成数据表明深度在 RGB 角点噪声较大时理论上可带来约 3 倍平移改善（7.117 → 2.442 mm），但这一潜力尚未在硬件上兑现。

**结论：深度融合代码链路完整、保守、可验证；当前硬件 + 黑色 Marker 组合下实测精度提升为 0。** 要兑现价值，第一优先级是换非黑 / 非镜面 Marker 重新验证深度覆盖，再用机械导轨 + 独立真值做 RGB-only 与 RGB-D 对照验收。

## 二、项目现状

### 2.1 定位目标

估计多面 ArUco 刚体在相机光学坐标系下的相对 6DoF，输出以首帧接受位姿为原点的轨迹（XYZ + 四元数 / RPY），并支持浏览器 3D 可视化。

### 2.2 两条硬件后端

| 后端 | 输入 | 定位方式 | 深度 |
| --- | --- | --- | --- |
| D455 | 彩色 + 原始深度点云 | 单面 IPPE / 多面联合 PnP，可选 RGB-D 融合 | 有 |
| T265 | 左右 848×800 Y8 鱼眼 | 双目各自估计 + SDK 外参转左眼系 + 一致性融合 | 无 |

### 2.3 处理管线

1. ArUco 检测 + 亚像素角点
2. 单面 IPPE 双候选解
3. 多面刚体标定 `T_reference_tag`
4. 联合角点 PnP
5. （可选）RGB-D 深度融合
6. 时序门控、丢失处理与分段
7. 相对 6DoF 轨迹

### 2.4 核心模块

| 模块 | 职责 |
| --- | --- |
| `localization.py` | 离线定位核心：ArUco、EPNP、联合 PnP |
| `tracking.py` | 刚体假设、单面 IPPE 候选、时序门控与分段 |
| `rgbd.py` | 无 SDK 依赖的 RGB-D 联合优化 |
| `realsense_depth.py` | 深度点云 → RGB 系、时间同步、跟踪器回调 |

### 2.5 当前完成度与精度基线

## 三、增加深度相机的机制

### 3.1 深度补的是什么

RGB-only 的 PnP 对景深（Z）方向最敏感，角点噪声会放大成 Z 误差。单个深度平面提供"法向方向 + 沿法向位置"两条约束，恰好补上这一维；而面内平移与绕法向旋转仍需 RGB 角点，因此 RGB 残差在任意 `depth_weight`（含 1.0）下都保留。

### 3.2 融合流程

1. 原始深度点云经真实 `T_color_depth` 外参变换到 RGB 光学系（不依赖 `rs.align`）
2. Marker 内部内缩 15% 提取 ROI 深度点，避开边缘与背景
3. 每面 RANSAC + SVD 拟合鲁棒平面，通过内点率 / RMS / 覆盖率 / 法向差等门控
4. soft_l1 联合优化「RGB 角点重投影残差 + 深度点到平面残差」；`depth_weight` 默认 0.2，按面与点数归一化
5. 保守回退：任何一步失败或破坏 RGB 重投影，都原样保留 RGB 位姿

### 3.3 关键语义

`depth_weight=0.2` 是归一化深度残差的相对权重，**不是 20% 位姿插值，也不是精度保证**。深度是"局部精修"，不参与 IPPE 候选分支重排。

## 四、实测效果

### 4.1 当前真实数据：接受率 0

| 指标 | 结果 |
| --- | --- |
| 深度与 RGB 系统性偏差 | +0.33 ~ +0.41 m |
| `depth_consistency_fraction_50mm` | ≈ 0 |
| 完整 877 帧 RGB-D 回放 · 接受深度精修 | 0 帧 |
| 几何不一致回退 | 834 帧 |
| 时间不同步回退 | 43 帧 |

根因是物理层面的：黑色 ArUco 油墨在 D455 深度图上大量返回无效值。因此当前 `--use-depth` 等价于 RGB-only，这是保守回退的预期行为，而非缺陷。

### 4.2 合成数据：潜在上限

独立噪声对照（48 mm Marker、0.85 m、0.35 px 角点噪声 + 1 mm 深度噪声）：20 个种子中 14 次接受，平移误差 **7.117 → 2.442 mm**，旋转 10.022 → 9.085°。说明当 RGB 角点噪声大而深度可信时，深度理论上可带来约 3 倍平移改善。此为合成噪声模型，非 D455 实测。

## 五、效果受限的三个层面

| 层面 | 原因 |
| --- | --- |
| 物理 | 黑色 Marker 深度缺失 → 无有效深度点 → 直接回退 |
| 几何 | 单平面只约束法向与沿法向平移；深度不参与 IPPE 分支重排，大角度双解翻转纠正不了 |
| 工程 | 全分辨率点云 + Python ROI 过滤开销大，实测未达 30 Hz |

## 六、结论与建议

1. 深度融合代码链路完整、保守、可验证（完整状态机 + 94 项测试兜底）。
2. 当前硬件 + 黑色 Marker 组合下实测精度提升为 0；深度真实收益仍需独立真值验收。
3. 第一优先级：换非黑 / 非镜面 Marker 重新验证深度覆盖，或调整曝光 / 距离 / 视角；再以机械导轨 + 独立参考系统做 RGB-only vs RGB-D 对照。
